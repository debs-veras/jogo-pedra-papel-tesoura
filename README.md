🪨✂️📄 Jogo Pedra, Papel e Tesoura

Esse é um projeto simples de um jogo clássico de Pedra, Papel e Tesoura desenvolvido com HTML, CSS, e JavaScript. O jogo permite que um usuário jogue contra o computador em uma partida básica com as regras tradicionais desse jogo de mãos.

🎮 Como Jogar

- Abra o arquivo index.html no seu navegador.
- Escolha uma das opções: Pedra, Papel ou Tesoura.
- O computador fará uma escolha aleatória.
- O resultado — vitória, derrota ou empate — será exibido na tela.

## Estrutura do Projeto

```
jogo-pedra-papel-tesoura/
├── index.html          # Página principal do jogo
├── src/
│   ├── css/
│   │   └── styles.css  # Estilos do jogo
│   └── js/
│       └── jogo.js     # Lógica do jogo
└── README.md           # Documento com instruções
```

## 🛠 Tecnologias Utilizadas

Este projeto usa as seguintes tecnologias:

- HTML5 – estrutura da página.
- CSS3 – estilos visuais.
- JavaScript – lógica do jogo e interação

## 💡 Regras do Jogo

As regras seguem o clássico:

- Pedra ganha de Tesoura
- Tesoura ganha de Papel
- Papel ganha de Pedra
