
# Jogo Pedra, Papel e Tesoura

Este é um projeto simples de um jogo Pedra, Papel e Tesoura desenvolvido com HTML, CSS e JavaScript.

## Como jogar

1. Abra o arquivo `index.html` em seu navegador.
2. Escolha entre Pedra, Papel ou Tesoura.
3. O computador fará uma escolha aleatória.
4. O resultado será exibido na tela.

## Estrutura do Projeto

```
index.html         # Página principal do jogo
src/
	css/
		styles.css     # Estilos do jogo
	js/
		jogo.js        # Lógica do jogo
```

## Tecnologias Utilizadas
- HTML5
- CSS3
- JavaScript
